# M0 Backend Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tested Django API that gives the pilot its foundation:
- tenants, users and roles
- warehouses and master data
- the RFID tag registry (TID + EPC, QR fallback)
- C72 device registration with PIN login
- per-warehouse power profiles
- an audit log
- tag intake: supplier rolls, bench sample checks, quarantine, verification on first bind (spec-002)
- exception cases with an inbox API: `tag_conflict`, `intake_failed` (spec-002)
- every tenant-owned table isolated by Postgres row-level security

**Architecture:**
- One Django project in `backend/` with four apps:
  - `tenancy`: tenants, users, warehouses, isolation, auth
  - `masterdata`: zones, locations, docks, items, partners
  - `rfid`: tags, tag batches (intake), devices, power profiles
  - `exceptions`: exception cases, one open case per problem
- Tenant-owned models inherit `TenantModel`. Each table gets a forced RLS policy keyed on the Postgres setting `app.tenant_id`.
- Every API request runs in one transaction (`ATOMIC_REQUESTS`). The tenant is set with `SET LOCAL` right after authentication, so it can never leak to another request.
- DRF viewsets filter by tenant as well, so isolation holds twice.

**Tech Stack:** Python 3.12 (via uv), Django 5.2 LTS, Django REST Framework 3.16, drf-spectacular, psycopg 3, PostgreSQL ≥ 14, pytest + pytest-django.

## Global Constraints

- Python `>=3.12`, Django `>=5.2,<5.3`, DRF `>=3.16,<4`, psycopg `>=3.2,<4`. Postgres ≥ 14.
- All endpoints live under `/api/v1/` with **no trailing slash**: `SimpleRouter(trailing_slash=False)`.
- **Tenant-owned tables:**
  - Every one inherits `tenancy.models.TenantModel` **and** gets `enable_rls("<table>")` in a migration.
  - The app and tests connect as the **non-superuser** role `wms_app`. Superusers bypass RLS.
- **No DELETE endpoints** for users, warehouses, master data or devices. Deactivate with `is_active=false` (NFR: history keeps its references).
- Server-side role checks follow [[roles-permissions]]. Platform staff (users with no tenant) cannot use the API; they use `/admin/`.
- **RFID rules:**
  - The TID is a tag's identity. The QR format is exactly `E=<epc hex>;T=<tid hex>`.
  - Hex is uppercased and has whitespace removed, and is 8–64 characters long.
  - Raw reads never reach the server.
- Model and field names come from [[glossary]].
- Secrets only via env (`backend/.env`, gitignored). Never print or log passwords, PINs, device keys or tokens, with one exception: the one-time admin password printed by `create_tenant`.
- Every new source file starts with a docstring that says what it is for (AGENTS.md §8.7).
- Commits use the Conventional Commits format, with **no AI attribution lines** (AGENTS.md §6.10). `VERSION` is bumped once, to `0.2.0`, in Task 15 (single PR).
- Run all `uv` commands from `backend/`.
- **A 4xx that must keep a write** (an audit row or an exception case) **returns** its `Response`; it never raises. DRF marks the request transaction for rollback on a raised error (`ATOMIC_REQUESTS`), which would drop the row.
- Raise and clear exception cases only through `exceptions.cases.open_case` / `close_cases`, keyed as spec-002 §4 says.

## Review Focus

Five ways this could fail in real use that no task's main tests target directly:

1. **Postgres superuser connection.** If the API or tests connect as a superuser, RLS silently does nothing. Expected: a hard failure. Pinned by the conftest guard (Task 1) and the forced-RLS check on every tenant table (Task 2).
2. **Tenant setting leaking between requests** on a reused DB connection. Expected: each request sees only its own tenant. Pinned by the alternating-tenant test (Task 3) and by `set_db_tenant` refusing to run outside a transaction (Task 2).
3. **Failed sign-ins disappearing from the audit log** because the request transaction rolled back. Expected: they are kept. Pinned by the `login_failed` / `device_login_failed` persistence tests (Tasks 6, 9).
4. **A request body pointing at another tenant's id** (warehouse, zone, location). Expected: a 400 response, never a 500 and never a cross-tenant link. Pinned in Tasks 4, 5 and 8.
5. **Badly formatted reads from a handheld:** lowercase or space-separated hex, or a QR code without a TID. Expected: normalized, or rejected with a 400 response. Pinned in Tasks 7 and 8.

Spec-002 adds three more:

6. **A refused bind losing its exception case** because the 400 rolled the request back. Expected: the `tag_conflict` case is kept. Pinned by `test_chip_with_a_different_epc_is_refused_and_the_case_survives_the_400` (Task 13).
7. **Supplier CSVs as they really arrive:** BOM, CRLF, a header row, blank lines, lowercase hex, stray spaces. Expected: imported cleanly, with bad lines listed by line number instead of failing the file. Pinned in Task 12.
8. **A bench submission resent after a Wi-Fi drop.** Expected: the same answer, with nothing counted twice. Pinned by `test_resending_the_same_txn_id_does_not_count_twice` (Task 13).

`backend/tenancy/tests/test_rls.py`:
```python
"""Row-level security is the backstop for tenant isolation (ADR-002). These tests query WITHOUT tenant filters on purpose."""
import pytest
from django.apps import apps
from django.db import IntegrityError, ProgrammingError, connection, transaction

from tenancy.context import set_db_tenant, tenant_context
from tenancy.models import TenantModel, User, Warehouse


def test_rows_of_other_tenants_are_invisible_without_any_orm_filter(make_tenant, make_warehouse):
    acme, bolt = make_tenant("acme"), make_tenant("bolt")
    make_warehouse(acme, "A1")
    make_warehouse(bolt, "B1")
    with tenant_context(acme.id):
        assert list(Warehouse.objects.values_list("code", flat=True)) == ["A1"]
    with tenant_context(bolt.id):
        assert list(Warehouse.objects.values_list("code", flat=True)) == ["B1"]


def test_no_tenant_set_means_no_rows(make_tenant, make_warehouse):
    make_warehouse(make_tenant("acme"), "A1")
    assert Warehouse.objects.count() == 0


def test_cannot_write_a_row_for_another_tenant(make_tenant):
    acme, bolt = make_tenant("acme"), make_tenant("bolt")
    with tenant_context(bolt.id):
        with pytest.raises(ProgrammingError, match="row-level security"), transaction.atomic():
            Warehouse.objects.create(tenant=acme, code="X1", name="Sneaky")


@pytest.mark.django_db
def test_every_tenant_owned_table_has_forced_rls():
    tables = sorted(m._meta.db_table for m in apps.get_models() if issubclass(m, TenantModel))
    assert tables, "expected at least one TenantModel"
    with connection.cursor() as cursor:
        cursor.execute(
            "SELECT relname FROM pg_class WHERE relname = ANY(%s) AND relrowsecurity AND relforcerowsecurity",
            [tables],
        )
        protected = sorted(row[0] for row in cursor.fetchall())
    assert protected == tables


@pytest.mark.django_db(transaction=True)
def test_setting_the_tenant_outside_a_transaction_is_refused():
    with pytest.raises(RuntimeError, match="inside a transaction"):
        set_db_tenant(1)


def test_tenant_user_must_have_a_role(make_tenant):
    acme = make_tenant("acme")
    with pytest.raises(IntegrityError), transaction.atomic():
        User.objects.create(username="norole", tenant=acme, role="")


@pytest.mark.django_db
def test_platform_staff_have_no_tenant_and_no_role():
    staff = User.objects.create(username="staff", is_staff=True)
    assert staff.tenant_id is None
    assert staff.role == ""
```

```python
"""Sets the current tenant on the DB connection so Postgres row-level security filters every query (ADR-002)."""
from contextlib import contextmanager

from django.db import connection, transaction


def set_db_tenant(tenant_id: int | None) -> None:
    """Scope the current transaction to one tenant (SET LOCAL). Outside a transaction the setting would vanish after
    one statement, so that is refused. API requests are transactions via ATOMIC_REQUESTS."""
    if not connection.in_atomic_block:
        raise RuntimeError("set_db_tenant() must run inside a transaction (ATOMIC_REQUESTS or transaction.atomic).")
    with connection.cursor() as cursor:
        cursor.execute("SELECT set_config('app.tenant_id', %s, true)", ["" if tenant_id is None else str(tenant_id)])


@contextmanager
def tenant_context(tenant_id: int):
    """Run a block as one tenant (scripts, management commands, tests). Restores the previous tenant on success;
    on an exception the savepoint rollback restores it."""
    with transaction.atomic():
        with connection.cursor() as cursor:
            cursor.execute("SELECT current_setting('app.tenant_id', true)")
            previous = cursor.fetchone()[0] or ""
        set_db_tenant(tenant_id)
        yield
        with connection.cursor() as cursor:
            cursor.execute("SELECT set_config('app.tenant_id', %s, true)", [previous])
```

```python
from django.db import migrations


def enable_rls(table: str) -> migrations.RunSQL:
    """Rows are visible and writable only when tenant_id equals the `app.tenant_id` setting.
    FORCE applies the policy to the table owner too (the app role owns its tables)."""
    return migrations.RunSQL(
        sql=f"""
            ALTER TABLE {table} ENABLE ROW LEVEL SECURITY;
            ALTER TABLE {table} FORCE ROW LEVEL SECURITY;
            CREATE POLICY tenant_isolation ON {table}
                USING (tenant_id = NULLIF(current_setting('app.tenant_id', true), '')::bigint)
                WITH CHECK (tenant_id = NULLIF(current_setting('app.tenant_id', true), '')::bigint);
        """,
        reverse_sql=f"""
            DROP POLICY IF EXISTS tenant_isolation ON {table};
            ALTER TABLE {table} NO FORCE ROW LEVEL SECURITY;
            ALTER TABLE {table} DISABLE ROW LEVEL SECURITY;
        """,
    )
```

```python
    """`user` and `tenant_id` default to the request's signed-in user. Never put secrets (passwords, PINs, keys) in `data`."""

        tenant_id=tenant_id,
        user=user,
        action=action,
```

```python
"""Server-side role checks (AGENTS.md invariant 2), following the matrix in wms-docs/roles-permissions.md."""
from rest_framework.permissions import SAFE_METHODS, BasePermission


class RolePermission(BasePermission):
    """Allows tenant users whose role is listed on the view.

    Lookup order: view.action_roles[view.action], then read_roles for safe methods, else write_roles.
    Platform staff (no tenant) are always refused: they use the Django admin.
    """

    message = "Your role is not allowed to do this."

    def has_permission(self, request, view):
        user = request.user
        if not (user and user.is_authenticated and user.tenant_id):
            return False
        action_roles = getattr(view, "action_roles", {})
        action = getattr(view, "action", None)
        if action in action_roles:
            roles = action_roles[action]
        elif request.method in SAFE_METHODS:
            roles = view.read_roles
        else:
            roles = view.write_roles
        return user.role in roles
```

```python
"""Base classes for tenant-owned API endpoints: RLS tenant context, tenant filtering, tenant stamping, auditing."""
from contextlib import contextmanager

from django.db import IntegrityError, transaction
from rest_framework import mixins, serializers, viewsets
from rest_framework.exceptions import ValidationError

from .audit import audit
from .context import set_db_tenant
from .models import ALL_ROLES, Role
from .permissions import RolePermission


@contextmanager
def _duplicates_as_400():
    try:
        with transaction.atomic():
            yield
    except IntegrityError as exc:
        raise ValidationError({"detail": "This conflicts with an existing record (duplicate code or name)."}) from exc


class TenantScopedMixin:
    """Mix into any DRF view that touches tenant-owned data. Authentication and role checks run first
    (super().initial), then the DB tenant is set, so Postgres RLS applies to every later query of the request."""

    permission_classes = [RolePermission]
    read_roles = ALL_ROLES
    write_roles = (Role.ADMIN,)
    action_roles: dict = {}

    def initial(self, request, *args, **kwargs):
        super().initial(request, *args, **kwargs)
        set_db_tenant(request.user.tenant_id)

    def get_queryset(self):
        return super().get_queryset().filter(tenant_id=self.request.user.tenant_id)

    def perform_create(self, serializer, **extra):
        with _duplicates_as_400():
            obj = serializer.save(tenant_id=self.request.user.tenant_id, **extra)
        audit(self.request, "create", obj)

    def perform_update(self, serializer):
        with _duplicates_as_400():
            obj = serializer.save()
        audit(self.request, "update", obj, fields=sorted(serializer.validated_data))


class TenantScopedViewSet(
    TenantScopedMixin,
    mixins.CreateModelMixin,
    mixins.RetrieveModelMixin,
    mixins.UpdateModelMixin,
    mixins.ListModelMixin,
    viewsets.GenericViewSet,
):
    """List, retrieve, create and PATCH. No DELETE: deactivate with is_active, so history keeps its references."""

    http_method_names = ["get", "post", "patch", "head", "options"]


class TenantPKField(serializers.PrimaryKeyRelatedField):
    """Foreign-key input limited to the caller's tenant. RLS enforces the same; this keeps the error a clean 400."""

    def get_queryset(self):
        return super().get_queryset().filter(tenant_id=self.context["request"].user.tenant_id)


def reject_changes(serializer, attrs, *fields) -> None:
    """On PATCH, refuse to change fields other rows depend on (e.g. a location's warehouse)."""
    if serializer.instance is None:
        return
    for field in fields:
        if field in attrs and attrs[field] != getattr(serializer.instance, field):
            raise serializers.ValidationError({field: "Cannot be changed after creation."})
```

```python
class UserSerializer(serializers.ModelSerializer):
    """Tenant users, managed by the tenant admin. Password and PIN are write-only and stored hashed."""

    # ponytail: usernames are unique across all tenants (Django default); fine for the pilot, revisit for 3PL scale.
    role = serializers.ChoiceField(choices=Role.choices)
    password = serializers.CharField(write_only=True, required=False, style={"input_type": "password"})
    pin = serializers.RegexField(r"^\d{4,8}$", write_only=True, required=False)
    warehouse_ids = serializers.ListField(child=serializers.IntegerField(), write_only=True, required=False)

    class Meta:
        model = User
        fields = ["id", "username", "email", "first_name", "last_name", "role", "is_active",
                  "password", "pin", "warehouse_ids"]

    def validate_password(self, value):
        password_validation.validate_password(value)
        return value

    def validate_warehouse_ids(self, ids):
        unique = set(ids)
        tenant_id = self.context["request"].user.tenant_id
        if Warehouse.objects.filter(tenant_id=tenant_id, id__in=unique).count() != len(unique):
            raise serializers.ValidationError("Unknown warehouse id for this tenant.")
        return sorted(unique)

    def validate(self, attrs):
        if self.instance is None and not attrs.get("password"):
            raise serializers.ValidationError({"password": "Required when creating a user."})
        return attrs

    def create(self, validated_data):
        password = validated_data.pop("password")
        pin = validated_data.pop("pin", None)
        warehouse_ids = validated_data.pop("warehouse_ids", [])
        user = User(**validated_data)
        user.set_password(password)
        if pin:
            user.set_pin(pin)
        user.save()
        self._set_warehouses(user, warehouse_ids)
        return user

    def update(self, user, validated_data):
        password = validated_data.pop("password", None)
        pin = validated_data.pop("pin", None)
        warehouse_ids = validated_data.pop("warehouse_ids", None)
        for field, value in validated_data.items():
            setattr(user, field, value)
        if password:
            user.set_password(password)
        if pin:
            user.set_pin(pin)
        user.save()
        if warehouse_ids is not None:
            self._set_warehouses(user, warehouse_ids)
        return user

    def to_representation(self, user):
        data = super().to_representation(user)
        data["warehouse_ids"] = sorted(user.warehouse_access.values_list("warehouse_id", flat=True))
        return data

    @staticmethod
    def _set_warehouses(user, warehouse_ids):
        WarehouseAccess.objects.filter(user=user).delete()
        WarehouseAccess.objects.bulk_create(
            [WarehouseAccess(tenant_id=user.tenant_id, user=user, warehouse_id=w) for w in warehouse_ids]
        )
```

```python
"""Tag reads as the server accepts them: normalized hex, plus the label QR format 'E=<epc>;T=<tid>' (ADR-005)."""
import re
from dataclasses import dataclass

_HEX = re.compile(r"[0-9A-F]{8,64}")


@dataclass(frozen=True)
class TagRead:
    epc: str
    tid: str = ""


def _normalize(value: str) -> str:
    return "".join(value.split()).upper()


def make_read(epc: str, tid: str = "") -> TagRead:
    """Validated, normalized read. A missing TID is allowed (far reads often lack it). Raises ValueError."""
    epc, tid = _normalize(epc), _normalize(tid)
    if not _HEX.fullmatch(epc):
        raise ValueError(f"EPC must be 8-64 hex characters, got {epc!r}.")
    if tid and not _HEX.fullmatch(tid):
        raise ValueError(f"TID must be 8-64 hex characters, got {tid!r}.")
    return TagRead(epc, tid)


def parse_qr(text: str) -> TagRead:
    """'E=3034...;T=E280...' → TagRead. Both parts are required: the QR exists to settle duplicate EPCs."""
    parts = {}
    for part in text.split(";"):
        if "=" in part:
            key, value = part.split("=", 1)
            parts[key.strip().upper()] = value
    if "E" not in parts or "T" not in parts:
        raise ValueError("QR must look like E=<epc>;T=<tid>.")
    return make_read(parts["E"], parts["T"])
```

```python
"""Tag registry rules (ADR-005): resolve reads, bind tags, retire tags, flag duplicate EPCs.

Callers must already be in the tenant's DB context (TenantScopedMixin or tenancy.context.tenant_context).
"""
from dataclasses import dataclass

from .models import Tag, TagStatus
from .reads import TagRead


class RegistryError(Exception):
    """A registry rule was broken. The message is safe to show to the operator."""


@dataclass(frozen=True)
class Resolution:
    """Outcome for one read. result: known | unknown | conflict | retired. flagged: this call newly marked a conflict."""

    epc: str
    tid: str
    result: str
    tag: Tag | None = None
    flagged: bool = False


def resolve(tenant_id: int, reads: list[TagRead]) -> list[Resolution]:
    return [_resolve_one(tenant_id, read) for read in reads]


def _resolve_one(tenant_id: int, read: TagRead) -> Resolution:
    tags = Tag.objects.filter(tenant_id=tenant_id)
    if read.tid:
        tag = tags.filter(tid=read.tid).first()
        if tag is None:
            twins = tags.filter(epc=read.epc).exclude(status=TagStatus.RETIRED)
            if not twins.exists():
                return Resolution(read.epc, read.tid, "unknown")
            # A chip we don't know carries an EPC we do know: duplicate EPC (supplier error or cloned tag).
            flagged = twins.exclude(status=TagStatus.CONFLICT).update(status=TagStatus.CONFLICT) > 0
            return Resolution(read.epc, read.tid, "conflict", flagged=flagged)
        if tag.status == TagStatus.RETIRED:
            return Resolution(read.epc, read.tid, "retired", tag)
        if tag.epc != read.epc:
            # Same chip, different EPC: re-encoded outside the WMS. Block it until a manager checks it.
            flagged = tag.status != TagStatus.CONFLICT
            if flagged:
                tag.status = TagStatus.CONFLICT
                tag.save(update_fields=["status", "updated_at"])
            return Resolution(read.epc, read.tid, "conflict", tag, flagged)
        # The TID proves identity, so a tag flagged for a duplicate EPC still resolves on a close read or QR scan.
        return Resolution(read.epc, read.tid, "known", tag)
    matches = list(tags.filter(epc=read.epc).exclude(status=TagStatus.RETIRED)[:2])
    if not matches:
        return Resolution(read.epc, "", "unknown")
    if len(matches) > 1 or matches[0].status == TagStatus.CONFLICT:
        return Resolution(read.epc, "", "conflict")
    return Resolution(read.epc, matches[0].tid, "known", matches[0])


def bind(tenant_id: int, read: TagRead, bound_type: str, bound_id: int) -> Tag:
    """Link a tag to a pallet, location or vehicle. Needs the TID (close read or QR), because binding fixes identity.
    One object may carry several tags (e.g. two pallet faces)."""
    if not read.tid:
        raise RegistryError("Binding needs the tag's TID: read it up close or scan its QR label.")
    tag, _ = Tag.objects.get_or_create(tenant_id=tenant_id, tid=read.tid, defaults={"epc": read.epc})
    if tag.status == TagStatus.RETIRED:
        raise RegistryError("This tag is retired and cannot be used again.")
    if tag.epc != read.epc:
        raise RegistryError("This chip reports a different EPC than when it was registered; a manager must check it.")
    if tag.bound_type and (tag.bound_type, tag.bound_id) != (bound_type, bound_id):
        raise RegistryError(f"This tag is already bound to {tag.bound_type} {tag.bound_id}; retire it first.")
    twins = Tag.objects.filter(tenant_id=tenant_id, epc=read.epc).exclude(pk=tag.pk).exclude(status=TagStatus.RETIRED)
    duplicate = twins.exists()
    if duplicate:
        twins.update(status=TagStatus.CONFLICT)
    tag.bound_type, tag.bound_id = bound_type, bound_id
    tag.status = TagStatus.CONFLICT if duplicate else TagStatus.BOUND
    tag.save()
    return tag


def retire(tag: Tag) -> None:
    """Retire a damaged or duplicate tag. A twin left alone with its EPC gets its normal status back."""
    tag.status = TagStatus.RETIRED
    tag.save(update_fields=["status", "updated_at"])
    twins = list(Tag.objects.filter(tenant_id=tag.tenant_id, epc=tag.epc).exclude(status=TagStatus.RETIRED))
    if len(twins) == 1:
        twin = twins[0]
        twin.status = TagStatus.BOUND if twin.bound_type else TagStatus.UNASSIGNED
        twin.save(update_fields=["status", "updated_at"])
```

```python
"""Serializers for the RFID API. Reads arrive as {epc, tid} from RFID or {qr} from the label fallback."""
from rest_framework import serializers

from .models import BoundType, Tag
from .reads import make_read, parse_qr


class TagSerializer(serializers.ModelSerializer):
    class Meta:
        model = Tag
        fields = ["id", "tid", "epc", "status", "bound_type", "bound_id", "updated_at"]


class TagReadSerializer(serializers.Serializer):
    """Validates one read into {"read": TagRead, "source": "rfid" | "qr"}."""

    epc = serializers.CharField(required=False, allow_blank=True, max_length=200)
    tid = serializers.CharField(required=False, allow_blank=True, max_length=200)
    qr = serializers.CharField(required=False, max_length=300)

    def validate(self, attrs):
        try:
            if attrs.get("qr"):
                return {"read": parse_qr(attrs["qr"]), "source": "qr"}
            return {"read": make_read(attrs.get("epc", ""), attrs.get("tid", "")), "source": "rfid"}
        except ValueError as exc:
            raise serializers.ValidationError(str(exc)) from exc


class ResolveRequestSerializer(serializers.Serializer):
    reads = TagReadSerializer(many=True, allow_empty=False, max_length=500)


class BindRequestSerializer(TagReadSerializer):
    bound_type = serializers.ChoiceField(choices=BoundType.choices)
    bound_id = serializers.IntegerField(min_value=1)

    def validate(self, attrs):
        return {**super().validate(attrs), "bound_type": attrs["bound_type"], "bound_id": attrs["bound_id"]}
```

```python
"""RFID API: tag registry (ADR-005). Clients send confirmed reads; raw read streams never reach the server."""
from rest_framework import status, viewsets
from rest_framework.decorators import action
from rest_framework.exceptions import ValidationError
from rest_framework.response import Response

from masterdata.models import Location
from tenancy.api import TenantScopedMixin
from tenancy.audit import audit
from tenancy.models import ALL_ROLES, Role, accessible_warehouse_ids

from . import registry
from .models import BoundType, Tag
from .serializers import BindRequestSerializer, ResolveRequestSerializer, TagSerializer


class TagViewSet(TenantScopedMixin, viewsets.ReadOnlyModelViewSet):
    queryset = Tag.objects.order_by("id")
    serializer_class = TagSerializer
    read_roles = (Role.ADMIN, Role.MANAGER)
    action_roles = {"resolve": ALL_ROLES, "bind": (Role.ADMIN, Role.MANAGER), "retire": (Role.ADMIN, Role.MANAGER)}

    def get_queryset(self):
        queryset = super().get_queryset()
        for field in ("status", "epc", "tid", "bound_type"):
            value = self.request.query_params.get(field)
            if value:
                queryset = queryset.filter(**{field: value.upper() if field in ("epc", "tid") else value})
        return queryset

    @action(detail=False, methods=["post"])
    def resolve(self, request):
        body = ResolveRequestSerializer(data=request.data)
        body.is_valid(raise_exception=True)
        results = registry.resolve(request.user.tenant_id, [r["read"] for r in body.validated_data["reads"]])
        for res in results:
            if res.flagged:
                audit(request, "tag_conflict", res.tag, epc=res.epc, tid=res.tid)
        return Response({"results": [
            {"epc": r.epc, "tid": r.tid, "result": r.result, "tag": TagSerializer(r.tag).data if r.tag else None}
            for r in results
        ]})

    @action(detail=False, methods=["post"])
    def bind(self, request):
        body = BindRequestSerializer(data=request.data)
        body.is_valid(raise_exception=True)
        data = body.validated_data
        if data["bound_type"] != BoundType.LOCATION:
            raise ValidationError({"bound_type": "Only location tags are bound in M0; pallet binding comes with receiving (M1)."})
        location = Location.objects.filter(tenant_id=request.user.tenant_id, pk=data["bound_id"]).first()
        allowed = accessible_warehouse_ids(request.user)
        if location is None or (allowed is not None and location.warehouse_id not in allowed):
            raise ValidationError({"bound_id": "Unknown location."})
        try:
            tag = registry.bind(request.user.tenant_id, data["read"], data["bound_type"], data["bound_id"])
        except registry.RegistryError as exc:
            raise ValidationError({"detail": str(exc)}) from exc
        audit(request, "tag_bind", tag, bound_type=tag.bound_type, bound_id=tag.bound_id, source=data["source"])
        return Response(TagSerializer(tag).data, status=status.HTTP_201_CREATED)

    @action(detail=True, methods=["post"])
    def retire(self, request, pk=None):
        tag = self.get_object()
        registry.retire(tag)
        audit(request, "tag_retire", tag)
        return Response(TagSerializer(tag).data)
```

```python
"""Handheld authentication: device keys for registered C72s and short-lived bearer tokens for operator sessions."""
import hashlib
import secrets
from datetime import timedelta

from django.utils import timezone
from rest_framework.authentication import BaseAuthentication, get_authorization_header
from rest_framework.exceptions import AuthenticationFailed

from tenancy.context import set_db_tenant

from .models import Device, DeviceSession

# ponytail: one shift. Make it a tenant setting if sites run longer shifts.
SESSION_TTL = timedelta(hours=12)


def sha256_hex(value: str) -> str:
    return hashlib.sha256(value.encode()).hexdigest()


def new_device_key(tenant_id: int) -> tuple[str, str]:
    """(key shown once to the admin, sha256 to store). The tenant-id prefix lets sign-in set the tenant before RLS."""
    key = f"{tenant_id}.{secrets.token_urlsafe(32)}"
    return key, sha256_hex(key)


def find_device(key: str) -> Device | None:
    """The active device for a raw key, or None. Sets the DB tenant from the key's prefix (call inside a transaction)."""
    tenant_part, _, secret = key.partition(".")
    if not tenant_part.isdigit() or not secret:
        return None
    set_db_tenant(int(tenant_part))
    return Device.objects.select_related("warehouse").filter(key_sha256=sha256_hex(key), is_active=True).first()


def start_session(user, device) -> tuple[str, DeviceSession]:
    token = secrets.token_urlsafe(32)
    session = DeviceSession.objects.create(
        key_sha256=sha256_hex(token), user=user, device=device, expires_at=timezone.now() + SESSION_TTL
    )
    return token, session


class DeviceTokenAuthentication(BaseAuthentication):
    """`Authorization: Bearer <token>` from POST /api/v1/auth/device-login. Refuses expired tokens, inactive users
    and deactivated devices, so deactivating a lost C72 ends its sessions at once."""

    def authenticate(self, request):
        header = get_authorization_header(request).decode("latin-1")
        if not header.startswith("Bearer "):
            return None
        session = (
            DeviceSession.objects.select_related("user")
            .filter(key_sha256=sha256_hex(header[7:].strip()), expires_at__gt=timezone.now())
            .first()
        )
        if session is None or not session.user.is_active:
            raise AuthenticationFailed("Invalid or expired token.")
        set_db_tenant(session.user.tenant_id)
        if not Device.objects.filter(pk=session.device_id, is_active=True).exists():
            raise AuthenticationFailed("This device was deactivated.")
        return session.user, session

    def authenticate_header(self, request):
        return "Bearer"
```

```python
def _can_use(user, device) -> bool:
    allowed = accessible_warehouse_ids(user)

class DeviceLoginView(APIView):
    """Operator sign-in on a registered C72: device key + username + PIN → 12-hour bearer token. Failures RETURN a
    401 instead of raising, so the request transaction commits and the failed sign-in stays in the audit log."""

    authentication_classes = []
    permission_classes = [AllowAny]
    throttle_classes = [ScopedRateThrottle]
    throttle_scope = "login"

    def post(self, request):
        body = DeviceLoginSerializer(data=request.data)
        body.is_valid(raise_exception=True)
        data = body.validated_data
        device = find_device(data["device_key"])
        user = User.objects.select_related("tenant").filter(username=data["username"], is_active=True).first()
        allowed = (
            device is not None
            and user is not None
            and user.tenant_id == device.tenant_id
            and user.tenant.is_active
            and user.check_pin(data["pin"])
            and _can_use(user, device)
        )
        if not allowed:
            audit(request, "device_login_failed", tenant_id=device.tenant_id if device else None,
                  username=data["username"])
            return Response({"detail": "Wrong device, username or PIN."}, status=status.HTTP_401_UNAUTHORIZED)
        token, session = start_session(user, device)
        device.last_seen_at = timezone.now()
        device.app_version = data.get("app_version", "")
        device.save(update_fields=["last_seen_at", "app_version"])
        audit(request, "device_login", device, user=user)
        return Response({
            "token": token,
            "expires_at": session.expires_at,
            "user": {"id": user.id, "username": user.username, "role": user.role},
            "warehouse": {"id": device.warehouse_id, "code": device.warehouse.code, "name": device.warehouse.name},
            "power_profiles": power_profiles(device.warehouse_id),
        })


class PowerProfileView(TenantScopedMixin, APIView):
    """Reader power (dBm) per task for one warehouse. Everyone with access reads; admins and managers change it."""

    write_roles = (Role.ADMIN, Role.MANAGER)

    def _warehouse(self, request, warehouse_id):
        warehouse = Warehouse.objects.filter(tenant_id=request.user.tenant_id, pk=warehouse_id).first()
        allowed = accessible_warehouse_ids(request.user)
        if warehouse is None or (allowed is not None and warehouse.id not in allowed):
            raise NotFound()
        return warehouse

    def get(self, request, warehouse_id):
        return Response(power_profiles(self._warehouse(request, warehouse_id).id))

                tenant_id=warehouse.tenant_id, warehouse=warehouse, name=name, defaults={"dbm": dbm}
            )
        audit(request, "power_profiles", warehouse, **body.validated_data)
        return Response(power_profiles(warehouse.id))
```

`backend/exceptions/cases.py`:
```python
"""open_case / close_cases: the only way code raises or clears exception cases (spec-002 §4, §6 step 5).
Call inside the tenant's DB context. Cases written during a request survive only if the request commits: a view
that answers 4xx but must keep its case RETURNS the Response instead of raising."""
from django.db import IntegrityError, transaction
from django.db.models import F
from django.utils import timezone

from .models import CaseStatus, ExceptionCase, Resolution

# Fields a repeat sighting may update on the open case; everything else stays as first recorded.
_BUMPABLE = {"seen_location", "txn_id", "data"}


def open_case(tenant_id: int, kind: str, key: str, **fields) -> ExceptionCase:
    """Open a case, or add one to `seen_count` of the open case with the same key.
    `fields`: warehouse_id, tag, batch, pallet_id, expected_location, seen_location, txn_id, data."""
    now = timezone.now()
    for _ in range(2):
        case = (ExceptionCase.objects.select_for_update()
                .filter(tenant_id=tenant_id, key=key, status=CaseStatus.OPEN).first())
        if case is not None:
            bump = {name: value for name, value in fields.items() if name in _BUMPABLE}
            ExceptionCase.objects.filter(pk=case.pk).update(seen_count=F("seen_count") + 1, last_seen_at=now, **bump)
            case.refresh_from_db()
            return case
        try:
            with transaction.atomic():
                return ExceptionCase.objects.create(tenant_id=tenant_id, kind=kind, key=key, last_seen_at=now, **fields)
        except IntegrityError:
            continue  # a concurrent request opened it first: loop once more and bump theirs
    raise RuntimeError(f"Could not open or bump exception case {key!r}.")


def close_cases(tenant_id: int, key: str, resolution: str = Resolution.FIXED, user=None, note: str = "") -> int:
    """Resolve the open case for `key`, if any. Returns how many rows changed (0 or 1)."""
    return ExceptionCase.objects.filter(tenant_id=tenant_id, key=key, status=CaseStatus.OPEN).update(
        status=CaseStatus.RESOLVED, resolution=resolution, resolved_at=timezone.now(), resolved_by=user, note=note
    )
```

```python
    """Newest first. Managers see their granted warehouses plus tenant-wide cases (no warehouse, e.g. a duplicate
    EPC found by a lookup); admins see everything in their tenant."""

    queryset = ExceptionCase.objects.order_by("-last_seen_at", "-id")
```

```python
def import_csv(batch: TagBatch, text: str) -> tuple[int, list[dict]]:
    """Create one unassigned Tag per valid `epc,tid` line. Bad lines are skipped and reported, never fatal.
    An optional header line starting with "epc," is ignored."""
    rejected, seen, valid = [], set(), []
    for number, raw in enumerate(text.splitlines(), start=1):
        line = raw.strip()
        if not line or (number == 1 and line.replace(" ", "").lower().startswith("epc,")):
            continue
        parts = line.split(",")
        if len(parts) != 2:
            rejected.append({"line": number, "reason": "Expected two columns: epc,tid."})
            continue
        try:
            read = make_read(parts[0], parts[1])
        except ValueError as exc:
            rejected.append({"line": number, "reason": str(exc)})
            continue
        if not read.tid:
            rejected.append({"line": number, "reason": "TID is required."})
        elif read.tid in seen:
            rejected.append({"line": number, "reason": "Duplicate TID in this file."})
        else:
            seen.add(read.tid)
            valid.append((number, read))

    registered = set(Tag.objects.filter(tenant_id=batch.tenant_id, tid__in=seen).values_list("tid", flat=True))
    new_tags = []
    for number, read in valid:
        if read.tid in registered:
            rejected.append({"line": number, "reason": "TID already registered."})
        else:
            new_tags.append(Tag(tenant_id=batch.tenant_id, batch=batch, tid=read.tid, epc=read.epc))
    Tag.objects.bulk_create(new_tags)
    _flag_duplicate_epcs(batch, {tag.epc for tag in new_tags})

    batch.imported = len(new_tags)
    batch.sample_size = min(DEFAULT_SAMPLE_SIZE, batch.imported) or DEFAULT_SAMPLE_SIZE
    batch.save(update_fields=["imported", "sample_size"])
    rejected.sort(key=lambda row: row["line"])
    return batch.imported, rejected


def _flag_duplicate_epcs(batch: TagBatch, epcs: set[str]) -> None:
    """An EPC carried by two live chips is a conflict (ADR-005): flag every chip and open one case per EPC."""
    live = Tag.objects.filter(tenant_id=batch.tenant_id, epc__in=epcs).exclude(status=TagStatus.RETIRED)
    for row in live.values("epc").annotate(chips=Count("id")).filter(chips__gt=1):

                  warehouse_id=batch.warehouse_id, batch=batch, data={"epc": row["epc"]})
```

```python
def run_checks(batch: TagBatch, pairs: list[tuple[TagRead, TagRead]]) -> list[dict]:
    """Judge (chip read, QR) pairs at the bench. A passing tag is verified (and registered, for a roll without a
    CSV); a failing tag of this roll is retired. Then the roll's status follows spec-002 §5."""
    now = timezone.now()
    results = []
    for chip, qr in pairs:
        tag = Tag.objects.filter(tenant_id=batch.tenant_id, tid=chip.tid).first()
        reason = _judge(batch, tag, chip, qr)
        if reason is None:
            if tag is None:
                tag = Tag.objects.create(tenant_id=batch.tenant_id, batch=batch, tid=chip.tid, epc=chip.epc)
            tag.verified_at = now
            tag.save(update_fields=["verified_at", "updated_at"])
            results.append({"tid": chip.tid, "passed": True})
        else:
            if tag is not None and tag.batch_id == batch.id and tag.status != TagStatus.RETIRED:
                registry.retire(tag, reason="failed_intake")
            results.append({"tid": chip.tid, "passed": False, "reason": reason})
    failures = sum(not row["passed"] for row in results)
    batch.checked += len(pairs)
    batch.failed += failures
    _update_status(batch, failures > 0)
    batch.save(update_fields=["checked", "failed", "status", "full_check"])
    return results


def _judge(batch: TagBatch, tag: Tag | None, chip: TagRead, qr: TagRead) -> str | None:
    if (chip.epc, chip.tid) != (qr.epc, qr.tid):
        return "chip_qr_mismatch"
    if tag is not None and tag.batch_id != batch.id:
        return "other_batch"
    if tag is None and batch.imported:
        return "not_in_batch"
    if tag is not None and tag.epc != chip.epc:
        return "epc_mismatch"
    if tag is not None and tag.status == TagStatus.RETIRED:
        return "retired"
    return None


def _update_status(batch: TagBatch, any_failed: bool) -> None:
    key = f"intake_failed:batch:{batch.id}"
    if any_failed and not batch.full_check:
        batch.status = TagBatchStatus.QUARANTINED
        open_case(batch.tenant_id, CaseKind.INTAKE_FAILED, key, warehouse_id=batch.warehouse_id, batch=batch,
                  data={"checked": batch.checked, "failed": batch.failed})
    elif batch.status == TagBatchStatus.IMPORTED and batch.checked >= batch.sample_size:
        batch.status = TagBatchStatus.ACCEPTED
    # ponytail: a quarantined roll without a CSV can't know it's fully checked; its tags bind one by one once verified.
    unchecked = batch.tags.filter(verified_at__isnull=True).exclude(status=TagStatus.RETIRED)
    if batch.status == TagBatchStatus.QUARANTINED and batch.imported and not unchecked.exists():
        batch.status = TagBatchStatus.ACCEPTED
        batch.full_check = True
        close_cases(batch.tenant_id, key)
```

```python
def bind(tenant_id: int, read: TagRead, bound_type: str, bound_id: int, *, chip_read: bool = True,
         warehouse_id: int | None = None) -> Tag:
    """Link a tag to a pallet, location or vehicle. Needs the TID (close read or QR), because binding fixes identity.
    One object may carry several tags (e.g. two pallet faces). A close read (`chip_read`) also verifies the tag
    (spec-002 §5 step 6); a QR bind proves only the label, so it doesn't."""
    if not read.tid:
        raise RegistryError("Binding needs the tag's TID: read it up close or scan its QR label.")
    tag, _ = Tag.objects.select_related("batch").get_or_create(
        tenant_id=tenant_id, tid=read.tid, defaults={"epc": read.epc}
    )
    if tag.status == TagStatus.RETIRED:
        raise RegistryError("This tag is retired and cannot be used again.")
    if tag.epc != read.epc:
        open_case(tenant_id, CaseKind.TAG_CONFLICT, f"tag_conflict:tid:{tag.tid}", tag=tag, warehouse_id=warehouse_id,
                  data={"registered_epc": tag.epc, "read_epc": read.epc})
        raise RegistryError("This chip reports a different EPC than when it was registered; a manager must check it.")
    if tag.batch_id and tag.batch.status == TagBatchStatus.QUARANTINED and tag.verified_at is None:
        raise RegistryError("This tag's roll is quarantined: check this tag at the tag intake bench first.")
    if tag.bound_type and (tag.bound_type, tag.bound_id) != (bound_type, bound_id):
        raise RegistryError(f"This tag is already bound to {tag.bound_type} {tag.bound_id}; retire it first.")
    twins = Tag.objects.filter(tenant_id=tenant_id, epc=read.epc).exclude(pk=tag.pk).exclude(status=TagStatus.RETIRED)
    duplicate = twins.exists()
    if duplicate:
        twins.update(status=TagStatus.CONFLICT)
        open_case(tenant_id, CaseKind.TAG_CONFLICT, f"tag_conflict:epc:{read.epc}", warehouse_id=warehouse_id,
                  data={"epc": read.epc, "tid": read.tid})
    tag.bound_type, tag.bound_id = bound_type, bound_id
    tag.status = TagStatus.CONFLICT if duplicate else TagStatus.BOUND
    if chip_read and tag.verified_at is None:
        tag.verified_at = timezone.now()
    tag.save()
    return tag
```

```python
        # A resent bench submission (Wi-Fi drop) is answered from the audit trail instead of being counted twice.
        prior = AuditEvent.objects.filter(tenant_id=request.user.tenant_id, action="tag_batch_check",
                                          data__txn_id=txn_id).first()
        if prior is not None:
            return Response(prior.data["response"])
        pairs = [(check["chip"], check["qr"]) for check in body.validated_data["checks"]]
        results = intake.run_checks(batch, pairs)
        payload = {"batch_status": batch.status, "results": results}
        audit(request, "tag_batch_check", batch, txn_id=txn_id, response=payload)
        return Response(payload)
```

````markdown
# API contract — M0 backend

What the React back office and the C72 app may rely on. Live machine-readable version: `GET /api/v1/schema?format=json`. Built by [[plans/2026-10-08-m0-backend]]; rules from [[specs/001-rfid-wms-pilot-design]] and [[roles-permissions]].

## Conventions
- Base `/api/v1/`, JSON, **no trailing slash**. Lists are paginated: `?limit=&offset=` → `{count, next, previous, results}`.
- **Web:** `GET auth/csrf`, then `POST auth/login`, which sets a session cookie. Send `X-CSRFToken` on writes.
- **C72:** `POST auth/device-login` returns a `token`. Send `Authorization: Bearer <token>`. It is valid for 12 h and dies when the device is deactivated.
- No DELETE: deactivate with `PATCH {"is_active": false}`.
- Errors: `400 {field: [msg]}`, `401` sign-in needed or failed, `403` role not allowed, `404` not found **or another tenant's**, `429` too many sign-in attempts (10/min).

## Endpoints

| Endpoint | Roles | Notes |
|---|---|---|
| `GET health` | public | `{status, version}` |
| `GET auth/csrf` · `POST auth/login` · `POST auth/logout` · `GET auth/me` · `POST auth/password` | web users | `me` = `{id, username, role, tenant{id,name}, warehouse_ids}` |
| `POST auth/device-login` | public (device key + PIN) | → `{token, expires_at, user{id,username,role}, warehouse{id,code,name}, power_profiles{single,pick,sweep}}` |
| `warehouses` (GET/POST/PATCH) | read all · write admin | non-admins see granted warehouses only |
| `warehouses/{id}/power-profiles` (GET/PUT) | read all · write admin, manager | dBm 1–30 per `single`/`pick`/`sweep` |
| `users` (GET/POST/PATCH) | admin | `password`, `pin` (4–8 digits) write-only; `warehouse_ids` |
| `zones` · `locations` · `docks` (GET/POST/PATCH) | read all (granted warehouses) · write admin | a location's zone must be in its warehouse; the warehouse can't change |
| `items` · `partners` (GET/POST/PATCH) | read all · write admin, manager | partner `kind` ∈ supplier/customer/carrier (`own` is system-made) |
| `devices` (GET/POST/PATCH) | read admin, manager · write admin | POST returns `key` **once** |
| `tags` (GET `?status=&epc=&tid=&bound_type=`) | admin, manager | registry rows `{id, tid, epc, status, bound_type, bound_id, batch, verified_at, retired_reason, last_seen{location{id,code}, at} \| null, updated_at}` |
| `POST tags/resolve` | all | body `{"reads": [{"epc","tid"?} \| {"qr"}]}`, 1–500 reads → `results[{epc, tid, result: known\|unknown\|conflict\|retired, tag\|null}]` |
| `POST tags/bind` | admin, manager | `{epc+tid \| qr, bound_type: "location", bound_id}`. The TID is required. Pallets come in M1. A close read sets `verified_at`; a QR bind doesn't. A tag from a quarantined roll must pass its bench check first. |
| `POST tags/{id}/retire` | admin, manager | a lone twin returns to `bound` |
| `tag-batches` (GET; POST multipart `{supplier, reference, warehouse, csv?}`) | admin, manager | POST → batch + `rejected[{line, reason}]`; CSV is `epc,tid` per line, max 20 000 rows / 2 MB |
| `POST tag-batches/{id}/checks` | admin, manager | `{txn_id, checks: [{chip{epc,tid}, qr: "E=…;T=…"}]}` (1–500) → `{batch_status, results[{tid, passed, reason?}]}`; same `txn_id` → same answer |
| `exceptions` (GET `?kind=&status=&warehouse=`) | admin, manager | open and resolved cases, newest first; managers see granted warehouses plus tenant-wide cases |
| `audit-events` (GET `?action=`) | admin | newest first |

## Tag rules the clients must honour ([[_meta/decisions/005-tag-identity-epc-tid-qr]])
- Send hex as read. The server uppercases it and strips spaces; it must be 8–64 characters.
- `conflict` on an EPC-only read: ask for a close read (to get the TID) or a QR scan.
- QR text is sent unchanged as `{"qr": "E=…;T=…"}`.
- Never stream raw reads. Send the de-duplicated set the operator confirmed.
````
